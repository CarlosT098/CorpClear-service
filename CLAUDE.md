# Agent Rules for Claude / AI Assistants

## Critical Rule: Do Not Commit
- **NÃO FAZER COMMIT**: Agentes NÃO devem executar `git commit`, `git push` ou criar commits de qualquer forma.
- O commit é feito exclusivamente de forma manual pelo desenvolvedor.
- Deixe todas as alterações no working directory para revisão.
- Consulte mais detalhes em [AGENTS.md](AGENTS.md) e [docs/agents/git-rules.md](docs/agents/git-rules.md).
